Sobre o Projeto

O que é o Agropanel?

O Agropanel é um sistema web desenvolvido para simular a gestão de um pequeno comércio agropecuário.

A aplicação permite cadastrar produtos, registrar compras e vendas, acompanhar o estoque e visualizar indicadores financeiros por período.

Objetivo como projeto de portfólio

O Agropanel foi desenvolvido como um projeto de portfólio com o objetivo de aplicar, em uma aplicação prática, conceitos de desenvolvimento web full stack, construção de APIs REST, integração com banco de dados e implementação de regras de negócio. Durante seu desenvolvimento, o foco foi buscar soluções que priorizassem organização, consistência dos dados e separação de responsabilidades.

Tecnologias Utilizadas

Frontend

HTML, CSS e JavaScript puro foram utilizados para construir uma interface responsiva, com foco em clareza, desempenho e interação direta com a API.

Backend

A API foi desenvolvida em Python com Flask, organizada em blueprints para separar as responsabilidades de produtos, compras, vendas, estatísticas e rotinas de demonstração.

Banco de Dados

O PostgreSQL armazena os dados da aplicação e concentra regras importantes de integridade, como relacionamentos entre produtos e movimentações de estoque.

Deploy

O frontend está hospedado no Vercel e a API no Render, com banco de dados PostgreSQL no Supabase.

Arquitetura

O Agropanel utiliza uma arquitetura cliente-servidor.

O frontend envia requisições HTTP para uma API REST. A API valida os dados recebidos, executa as regras de negócio e se comunica com o banco PostgreSQL. Em seguida, os dados retornam em JSON e são exibidos nas tabelas, cards e gráficos do painel.

Modelo de Dados

A aplicação possui três entidades principais:

  • Produtos: catálogo de itens, preço padrão de venda e estoque atual.
  • Compras: entradas de mercadorias, com fornecedor, valor, quantidade e data.
  • Vendas: saídas de mercadorias, com comprador, valor, quantidade e data.

Compras aumentam o estoque e vendas o reduzem. Cada compra ou venda está vinculada a um produto.

Decisões Técnicas

  • Uso de blueprints no Flask para manter as rotas organizadas por domínio.
  • Uso de SQLAlchemy Core com queries parametrizadas para comunicação com o banco.
  • Uso de triggers no PostgreSQL para atualizar o estoque automaticamente em inclusões, alterações e exclusões de compras e vendas.
  • Validações no backend para campos obrigatórios, campos permitidos, valores negativos e registros inexistentes.
  • Uso de modal de carregamento para comunicar a possível inicialização da API no plano gratuito do Render.
  • Dashboard com Chart.js para visualizar a receita por produto.

API

A API segue um padrão REST e disponibiliza operações de criação, consulta, alteração e exclusão para produtos, compras e vendas.

Também possui uma rota de estatísticas que calcula receita, despesa, resultado do período e os produtos com maior receita no mês selecionado.

Experiência e Deploy

Como este é um projeto demonstrativo hospedado em serviços gratuitos, a API pode levar alguns segundos para iniciar após um período sem acessos. A interface informa essa situação ao visitante e oferece uma opção para recarregar em caso de falha de conexão.

O objetivo do Agropanel foi construir uma aplicação funcional de ponta a ponta, explorando integração entre frontend, API, banco de dados e regras de negócio.
